# 两分钟启动

2026-11-07。依据 Codex 整理的《「两分钟启动」功能开发交接文档》，使用逻辑参考「滚雪球」，UI 沿用显伴自己的样式。

> 把任务变得不靠意志也能做。帮想做事却迟迟开始不了的人，把事情拆成几个极小、容易做的动作，小光陪着一步一步开始。

---

## 一、用起来是什么样

**入口**
- 点子 → 日常 →「两分钟启动」。
- 蜕变计划里每个待做小步旁边的小播放键：任务直接填好，小光知道它挂在哪个愿望下。

**1. 写下想做的事、选模式**
- 小光问「想做哪件事？说一件就好。」，下面一个输入框。
- 两个可选的模式：「低能量」「拆更准」，都不选就是默认。选中时下面一行小字说明（动作更小更温和 / 先回答三个小问题）。
- 「从小步开始」：蜕变计划里待做的小步（当前愿望的排前面，最多 4 个），一行一个，点一下就填好，小光也知道它挂在哪个愿望下。只做这一种快速启动，不放「开始专注」「睡前放松」这类场景预设，也不列最近做过的事。
- 上次没做完的（6 小时内）会出现「接着做『想起床』第 2/4 步」。

**2. 拆更准（只在这个模式）**
- 一页三个问题：你现在做到哪了？你现在最想推进的是什么？你现在最大的阻碍是什么？
- 每个问题有 4 个贴着这件事的快捷选项（模型现生成，比如写论文时是「开了文档写了个标题」「怕写出来很烂」），也能在「其他」里自己写。答一个就能继续。

**3. 一次一个动作**
- 上：进度条和「2/5」。中：小光说一句（开场白、调整后的回应，或「好，下一个」），下面一张卡片：动作标题、怎么做、约几分钟，再下面一行「接下来：……」；从小步进来的会写「来自小步『……』」。
- 下：「完成这一步」（主按钮，占满一行），下面并排「调整路线」「遇到困难」。
- 调整路线 / 遇到困难是底部弹层：上面是「现在这一步」，中间是这一次里你说过的话和小光的回应，下面是快捷反馈和输入框。
  - 调整路线：再小一点 / 换个做法 / 这步我已经做过了 / 顺序换一下。
  - 遇到困难：不想动 / 做不到这一步 / 被打断了 / 不知道怎么做，加两个不用问模型的：「先跳过这一步」「今天先到这儿」。
  - 手机上：四个快捷反馈排成两列一样大的按钮（手指好点），下面是输入框，「先跳过这一步」「今天先到这儿」单独一行、颜色更淡，和反馈分开。拆更准的选项也是两列。
  - 发出去后，小光只改「现在这一步和后面的」，做完的不动，弹层收起，卡片换成新的，气泡里是小光的回应。不会跳到聊天页。

**4. 你已经开始了。**
- 标题「你已经开始了。」，下面「完成了 N 步」（中途停下的还会写「还有 M 步没做」），小光说一句鼓励（生成路线时一起写好的，具体到这件事）。
- 一个复选框「让小光记住这次体验」，**默认不勾**。
- 「继续做这件事」：全部做完时，小光接着刚才的进度再给 2～4 步（同一次会话）；中途停下的，接着做剩下的。
- 「结束」：勾了就存进《两分钟启动记忆》，没勾什么都不留。
- 走完一条路线算一次练习：+12 经验、+10 金币，每日任务「做 1 次练习」也算。

## 二、独立的提示词（`demo/core/kickstart.py`）

不复用聊天的人设、工具和长期记忆，自己一套：

- **系统提示**：你是小光，在「两分钟启动」里陪 TA 把事情做起来。动作 1～3 分钟、身体能直接做（起身、拿起、打开、写下一句），第一个小到几乎不用意志力；标题 ≤10 字、说明 ≤30 字；不知道的别假设（不知道家里有什么就别写「拿出瑜伽垫」）；不讲道理、不分析拖延、不贴标签、不说「加油」。说话方式跟着 TA 选的小光性格（温柔 / 有条理 / 活泼）。
- **三种模式只差一段规则**：默认 3～5 步、最后落到真正开始；低能量 3～4 步、更小更温和、可以先让身体动一下、停在「已经开始了」就好；拆更准照三问的回答，从做到的地方接着往下，第一步冲着最大的阻碍去，最后落到最想推进的。
- **读的上下文只有这些**：现在几点、称呼、有精神的时候、希望怎么陪；用这件事去检索的 3 条相关记忆；以前存下的、和这件事相关的启动经历最多 2 条；从蜕变计划进来时的小步和愿望；这一次的任务、模式、三问回答、路线（✓ 做完 / → 现在 / · 没做 / 跳过）和这一次里的全部反馈。
- **四种请求**：生成拆更准的快捷选项、生成路线、改路线（调整路线 / 遇到困难，只返回从现在这一步开始的新路线）、继续（接在后面再给几步）。都要求只输出 JSON，路线是结构化的 `{title, tip, minutes}`。
- **速度**：这里关掉了模型的思考（`llm.complete_json(reasoning=None)`，用配置里的默认），用户在等着看。实测 DeepSeek：问题 2.5 秒、路线 3.0 秒、改路线 2.8 秒。其他后台调用照旧。
- **出错时**：生成路线失败，给一条最朴素的三步路（把要用的东西拿出来 / 只做最小的一下 / 停一下看看），小光说「我这会儿有点慢，先按最简单的来」，不让人卡住；拆更准的选项生成失败用一组通用选项；改路线 / 继续失败，路线不动，提示「刚才没想好，换个说法再试一次？」；同一个人一分钟内点太多次会让歇一会儿。

一次启动的状态存在 `kick_run` 表（任务、模式、蜕变计划上下文、三问回答、路线、现在第几步、反馈记录）。刷新页面不丢，6 小时内能接着做；开始新的一件事时，之前没结束的那次按「没勾记住」处理。

## 三、《两分钟启动记忆》和小光的长期记忆

**写入**：只有结束时勾了「让小光记住这次体验」，才写一条到 `kick_memory` 表（每个用户自己的数据库里，独立于「小光记得的」那些记忆）。内容是一段文字加完整的结构化数据，例如：

```
11月7日 21:30｜开始写周报（拆更准）
状态：现在做到：写了个开头；最想推进：写完第一段；最大的阻碍：怕写不好
一开始的路线：打开周报文档 → 写一句最简单的 → 列三个关键词
跳过了「写一句最简单的」
遇到困难：TA 说「一打开文档就想刷手机」，「列三个关键词」换成了「手机打三个词」
做完以后想继续，接着加了 1 步
实际做了：打开周报文档、手机打三个词、再写三句（3/4 步）
```

只存这一次的事，不存无关的对话。**没勾**：这一次的三问回答、反馈和路线细节都清掉，只留任务、模式和走了几步（统计用）；中途关掉也一样。

**① 夜里的记忆整理**（`core/digest.py`）：每天的材料里多一块「两分钟启动记忆」，TA 在里面说过的原话（反馈、三问回答）也算进当天的原话，改受保护记忆时可以拿来当依据。整理的提示里加了一条：从中找常见的阻碍、对 TA 管用的启动方式、行为规律，写进记忆或笔记本；**只出现一次的经历最多记成带日期的事件，不当成稳定的偏好**；记过的不重复。用的是现有的夜间整理，没有另建定时任务。

**② 聊天里按需查**（`core/agent.py`）：新工具 `kick_history(query)`。TA 问「上次我是怎么开始练琴的？」时，小光去查，照记录回答；没有记录就照实说（只有勾了「记住」的才会留下）。平时聊天不加载这些记录。聊天提示里另加了一句：TA 说一件事想做却一直开始不了时，可以提一下点子里的「两分钟启动」。

**能看、能删**：我的空间 → 记忆，最下面一个可以展开的「两分钟启动记忆 · N 次」，每条能删。导出数据（/api/export）里也有。

## 四、和文档不一样、或者文档没写的地方

- **模式的选法**：参考滚雪球，做成两个可选的小按钮（低能量 / 拆更准），都不选就是默认，没有单独的「默认」按钮。
- **完成这一步之外的两个按钮**放在主按钮下面并排，和滚雪球一样；没有做计时器和语音。
- **「先跳过这一步」「今天先到这儿」**放在「遇到困难」里：跳过不用等模型；先到这儿直接去「你已经开始了」，那里也能存记忆。这两个是为了「减少用户退出」加的。
- **「继续做这件事」**：全部做完时向模型要新的几步；中途停下的，接着做剩下的。
- **我的空间里能看、能删存下的启动记忆**。文档说不加独立历史页，这里只是在现有的记忆页底下加了一个折叠块，用户授权存的东西总得能看、能删。
- **入口**：点子里一个，蜕变计划每个待做小步旁边一个小播放键（文档说「如从蜕变计划进入」）。
- 没有做：收藏路线、偏好管理、单独的历史页（文档要求不加）；滚雪球底部那排场景预设（开始专注、睡前放松、晨间 SOP）也没有做，快速启动只针对蜕变计划里的小步。

## 六、测试和验证

- 接口测试 82 个全部通过。新加的三个覆盖：
  - 低能量路线；完成两步后调整路线，只改现在和后面的；第二轮遇到困难还记得第一轮的话；走完给练习经验；不勾记住时什么都不留。
  - 拆更准的问题和选项；按回答生成路线；跳过；继续；勾了记住后的记忆文字；夜里整理能读到，原话也在；`kick_history` 查得到 / 查不到；在我的空间里删。
  - 从蜕变计划的小步进来；模型不在时的兜底路线；改路线失败的提示；刷新后接着做；中途关掉。
- 浏览器里用真模型走了一遍（手机宽度）：入口、低能量路线、完成这一步、刷新后接着做、调整路线（「房间好冷，不想离开被窝」→ 先披件外套）、遇到困难弹层里显示这一次的对话。
- 用真模型单独跑了一遍拆更准（写课程论文），结果见第二节的速度和这里：
  - 选项：「开了文档写了个标题」「怕写出来很烂」……
  - 路线：写下第一句 → 打三个要点 → 给每个要点写一句 → 把它们接起来 → 改开头那一句。
  - 遇到困难「一打开文档就想刷手机」→「我们先不打开它，就用手机记三个词」，做完的那步没动。
- 走查时发现并修好两处：「完成这一步」按钮把点击事件当成了动作名；调整路线的弹层被全屏页盖住（z-index）。
- 手机宽度（375）下又走了一遍：写下想做的事 /「从小步开始」/ 接着做；两个弹层的按钮排列（2×2，每个 146×46）；拆更准的三个问题；做完四步、勾选记住、结束，我的空间里能看到这一条。
