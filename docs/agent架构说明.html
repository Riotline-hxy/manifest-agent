显伴 · 小光 Agent 系统说明

对应 v3.22.0（2026-11-12，在审查分支上，还没上线）。全部内容按现在的代码整理；文件位置写在每一节的小字里，方便对照。

说明里的「小光」指陪伴者；用户给它改了名字后，提示词和界面都会用新名字。「TA」指用户。字数都是中文字符数，1 个 token 大约 1–1.5 个中文字。

二、一轮对话是怎么走的

用户发一句话，到小光回完、存下来。代码：agent.chat()

① 收到这句话存进聊天记录；标记主动消息已读；每天第一次来聊 +8 经验（陪伴，不给金币）
② 记忆记得的事整份放进系统提示（按六类，约 2,400 字以内，多数人全部放得下）。只有记忆多到放不下时，才按「这句话 + TA 上一句」去检索放不下的那部分，补最多 4 条；对不上就不补
③ 拼提示词系统提示（人设、说话样子、App 地图、你知道的、记得的事、近况笔记……）+ 最近三天的原话 + 本轮补充说明 + 这句话。详见第三节
同时开始两件事
④a 路由判断（小模型调用）「TA 这句是不是要我现在做一件事？」只输出一个工具名或空。约 1.6–2 秒，和④b 并行，最多等 4 秒。
例外：小光刚问「要不要留成一个瞬间」、TA 只回「好呀」，由代码直接判断要存下，不问路由
④b 主模型开始流式回复第一个事件先扣住，等路由的结论：路由说该调 X、而模型没在调 X → 丢掉这一轮，强制它先调 X 重来
工具循环（最多 4 轮）
⑤ 模型要调工具代码先做三道把关（第四节）：TA 这句话有没有让改 · 删的是不是 TA 点了名的那一项 · 记忆 / 偷懒 / 打勾有没有对得上的原话
⑥ 在这个用户的库上执行，拿到真实回执回执交回给模型；同时变成界面上的卡片：推荐功能入口 · 回执做了什么（24 小时内可撤销）· 待确认提议的计划 / 瞬间，TA 点了才存
模型看完回执，再说话或再调工具
⑦ 文字一边生成一边推给手机
⑧ 收尾的兜底一个字没说 → 再要一次「只说话」；还不说 → 照真实做了的事给一句最短的话 · 嘴上推荐了练习却没调工具 → 补入口 · 嘴上问「要不要留成一个瞬间」却没调工具 → 补「留下」卡片 · 同一个愿望出了新一版计划 → 旧卡片作废
⑨ 存下回复和卡片卡片存在这条回复里，翻回去看还在；下一轮会把「你提议过什么、TA 点没点」写成一条说明给模型
一轮要调几次模型
路由1 次
主模型1 次（不调工具）
2–5 次（每调一轮工具多一次）
兜底偶尔 +1

实测（6 路并发）：不调工具首字中位 2.3 秒；调了工具约 5 秒。

话题模式

从点子里点了「话题」，30 分钟内的对话会在系统提示后面接上话题提示词；这期间不走路由、不打开别的练习。

每轮不自动记东西

聊天里随口说的事，不会当场写进记忆，交给夜里统一整理（第七节）。逐轮抽取的代码还在，但默认关着。

v3.22 合并了 7 个：add_habit add_step adjust_habit → edit_plan；get_growth → look_up(growth)；search_memory search_chats kick_history → search_past。另外删掉了 3 个从来没给过模型的工具的处理代码。

写入前的三道把关（代码做，不靠模型自觉）

模型说：我要改 TA 的东西
① TA 这句话有没有让改改计划、提醒、设置、习惯这几个工具：TA 这句里有「删 / 改 / 加 / 挪 / 提醒我……」这类说法，或者是在同意小光上一句的提问，或者路由判断就是要做这件事。否则返回「先问 TA」
② 删的是不是 TA 点了名的看 TA 的原话，不看模型填的目标：两个习惯都叫「背单词」时，模型自己挑一个（哪怕填了准确 id）也拦下，让它先问是哪一个。TA 说「都删了」或小光刚提议过这一项除外
③ 特定工具的原话检查记忆：要有「记住 / 记一下」或在同意记 · 偷懒日：要说了「休息 / 躺平」，只说累不算 · 打勾：说的事要和那个小步对得上 · 瞬间：只能提议，TA 点「留下」或明确说「留着」才存
没过：告诉模型原因，这一轮这个工具不再给它
都过了才执行；回执是真实结果，模型不能说没发生的事

还有几条硬边界：小镇只能 TA 自己点着买和摆；学堂只读；经验金币只由后端规则计算，模型和前端都只能读。

六、更正和忘掉

同一件事会出现在好几个地方，所以「忘掉」要在每个地方都生效。代码：memory.py 末尾

TA 在「小光记得的」点忘掉 / 改，或者在聊天里说「那条不对」
记忆表删掉或改写那一条，修订记录留下旧说法
笔记本当场把说这件事的那半句拿掉
对话上下文之前聊天原话里说到它的那句不再带给模型。更正的，本轮说明里写「旧 → 新」；删掉的不再点名：哪里都没有它了，再写一句「别提 X」反而把 X 摆到模型眼前（实测：这样改后被提起的次数更少）
夜里整理提示里列出 TA 删掉的；模型还想写回去（记忆或笔记本）也会被代码拦下
TA 之后自己又说起这件事，照 TA 现在说的来

manifest_flow.py		显化七步，一步一屏：清晰愿景 → 消除怀疑 → 调整行为 → 克服考验 → 无条件感恩 → 嫉妒变动力 → 信任。新愿望走七步，已有愿望从第 2 步开始。每题都能自己写、能回上一步每步 1 次 + 结尾小纸条 1 次（共 10 个小提示词）新愿望 · 肯定语、感恩进记忆 · 今天的行动成小步 · 怀疑和考验进记忆（默认不勾）· 每天 08:00 念肯定语的提醒（默认不勾）
调整现有计划
relearn.py		三个小问题（状态、劲头、计划做得怎样）+ 整份计划 → 一份方案：一句「看到的你」+ 0–5 条具体改动。可取消某条或说一句重调。改动只能是几种固定类型，对不上计划里真实一项的不给看出方案 1 次，每次重调 1 次「一键调整」勾了的改动 · 勾了「记住现在的你」才记一条近况
两分钟启动
kickstart.py, kick_prompts.py		写一件开始不了的事 → 选默认 / 低能量 / 拆更准（先答三问）→ 3–5 个一两分钟的小动作，一次一个。每步可「完成 / 调整路线 / 遇到困难」，只改现在和后面的开始 1 次（拆更准多 1 次）+ 每次调整 1 次勾了「让小光记住」才写进《两分钟启动记忆》；不勾或中途关掉、6 小时没回来：回答和路线都清掉
冥想
scenes.py		六屏固定引导，有背景音乐不调结束时三选一：写下感受（进记忆）/ 和小光聊聊（小光先提一句刚才的画面）/ 直接结束
三分钟感恩
scenes.py		三题：一件好事、跟人有关的、跟自己有关的不调答完就写进记忆和聊天记录（唯一一个不需要确认的）
话题
topics.py		三个：完全空白的一天 / 我的使用说明书 / 平行宇宙里的你。点了替 TA 发一句，话题提示词接在系统提示后面就是普通对话不单独存，走对话里的工具

这些练习都用自己的提示词，不复用聊天的人设长文；但会带上 TA 起的名字、选的性格和称呼。练习经验在答完时给，同一次只给一次。

3. 计划、成长、小镇（规则，不调模型）

蜕变计划愿望（最多 6 个）→ 里程碑、习惯（每天或每周 N 次）、小步（做一次就完成，可安排到某天，过了不算逾期）。偷懒日：今天安排的小步挪到明天，什么进度都不扣
经验和金币按「来源 + 引用」记账，同一件事只算一次。经验每类每天 30、总共 120；聊天只给经验不给金币；每日任务四件。撤销时把那一笔经验扣回（金币已经花掉的不倒扣）
小镇等级解锁建筑和更大的地；买 = 扣金币 + 放下，一个事务里完成，同一次点击重发不会扣两次

4. 界面上的三种卡片（对话里小光做的事怎么显示）

推荐一个功能入口：图标、名字、一句介绍、「开始」。TA 点了才打开
回执一行「做了什么：旧 → 新」。24 小时内、之后没再改过的可以撤销（数据和那一笔经验一起退；金币已经花掉的不倒扣）
待确认提议的计划（逐项勾选再「加进计划」）、提议的瞬间（点「留下」才存）。点完原地变成结果
