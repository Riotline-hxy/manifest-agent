# 点子改版（二）：精简成四个，冥想换成「遇见更好的自己」

2026-11-05。依据《冥想体验：遇见更好的自己》，以及讨论时的两点：

- 点子里删掉「你现在有多了解我」「说清想要的」，因为和别的功能没有区别度；
- 冥想按文档重做，配一段能让人清空大脑的背景音乐（Pixabay：Soothing Meditation (Without Voice)）。

上一轮的两个「聊聊」见 [点子改版-两个聊聊.md](点子改版-两个聊聊.md)，这一轮沿用同一套「先确认再存」的做法。

## 一、点子现在是什么样

| 分组 | 练习 | 时长 |
|---|---|---|
| 聊聊 · 答几个小问题，小光更懂你 | 聊聊现在的你、聊聊你的愿望 | 各约 2 分钟 |
| 日常 · 几分钟就能做完 | 遇见更好的自己、三分钟感恩 | 约 3 分钟 |

- 删掉两个以后，原来的「默契」「愿望」两组各只剩一个，所以合成一组「聊聊」。不想改分组的话，在 `core/api.py` 里把 `group` 改回去、`views/ideas.js` 的 `GROUPS` 加回来就行。
- 「你现在有多了解我」原来只是往对话里发一句话。用户想知道，直接在聊天里问小光就行，小光的功能说明里也写了。
- 「说清想要的」整个删了（题目、写回规则、测试）。
- 老数据照常：以前做过的次数、记忆、小步都在。上线前做到一半的「说清想要的」，再答一题会提示「这个练习已经下架了」并结束，不会报错。今天的「今日推荐」如果正好是它，只换掉推荐的练习，今天的四件每日任务不动。
- 体验账号的示例数据里，原来那次「说清想要的」换成了「聊聊你的愿望」。

## 二、遇见更好的自己

### 入口

- 标题：冥想体验：遇见更好的自己（2026-11-05 起；最初上线时叫「遇见更好的自己」）
- 介绍：花几分钟放松一下，想象你期待的生活。
- 约 3 分钟；按钮「开始」

### 六页

| 页 | 内容 | 交互 |
|---|---|---|
| 1 先放松下来 | 找一个舒服的姿势。 / 轻轻吸一口气，再慢慢呼出来。 / 这一刻，你可以先放下手里的事。 | 一颗慢慢呼吸的光；话说完，「准备好了」才亮 |
| 2 选择想去的地方 | 想象一年后的某一天……你希望自己在哪里？ | 5 个选项，选了直接进下一页；「其他，我有自己的画面」不要求输入 |
| 3 看看未来的自己 | 你最希望那时的自己是什么样的？ | 5 个选项；选了以后小光说：「那是你期待成为的样子。我们一起再看看，那时的你过着怎样的生活。」点「继续」 |
| 4 感受生活中的美好 | 未来的你刚刚经历了一件让自己开心的事，你希望是什么？ | 5 个选项，选了直接进下一页 |
| 5 让美好的感觉靠近 | 想象一束温暖的光……你希望它带来什么？ | 5 个选项；选了以后那颗光变成暖色，小光说「你选择了 X。现在，试着在心里对自己说：……」（五句和文档的表一致），点「继续」 |
| 6 带着期待回来 | 再轻轻呼吸一次。 / 感受一下你的身体，也留意身边的声音。 / 等你准备好了，慢慢睁开眼睛，或者抬起目光。 / 欢迎回来。 | 呼吸的光；话说完，「我准备好了」才亮 |

节奏上的处理（文档没写，我定的）：

- 每一页的话一行一行慢慢出来（每行隔 0.9 秒），选项和按钮等话说完再出来，读着像有人在带。
- 选择页选了就往下走，所以这些页不放「继续」按钮；也不放「跳过」，每题都有一个可以随便选的选项。
- 翻页时整页淡出淡入，不像别的练习那样底栏闪绿、说「记下了」。
- 小光在放松和回来的两页是闭眼的样子（「陪你慢一点」），提问时在听，回应时笑。
- 整个练习只有一颗光，放松、回来时慢慢呼吸（8 秒一吸一呼），第 5 页变暖。系统开了「减少动态效果」时，光不动，话也不逐行出现。

**改了一个字**：文档第 3 页的回应是「我们一起再看看**她**的生活」。用户不一定是女生，所以改成「我们一起再看看，那时的你过着怎样的生活」。

### 结束页：留下一点感受

「刚刚的几分钟里，有没有什么让你想记住？」

| 选项 | 做什么 |
|---|---|
| 我想记下刚才的感受 | 出输入框（下面一行小字「会记在『好消息』里」），底部换成「不保存」「保存」。保存后记成好消息里的一颗**小确幸**，前面带「冥想后：」，留在原来的页面 |
| 我想和你聊聊 | 进对话页。小光先开口提一句刚才的画面，比如「刚才那几分钟，你在阳光下的户外，看到了更平静的自己，那束光带来了自信。想从哪儿聊起都行。」用户接着说，小光也知道刚才想象了什么 |
| 先不记录，结束 | 回到原来的页面，什么都不留 |

- 冥想里选的地方、样子、光，**都不存**，也不进聊天记录。只有用户点了「和你聊聊」，小光那句开场白才进对话。
- 感受记成小确幸是我定的：老版冥想就是把感受记成好消息里的一颗星，而且这是用户想「记住」的东西，好消息页是他们回头翻的地方。想换成内心戏或别处，改 `scenes._meditation_note` 一处就行。
- 经验照旧答完就给（+12 经验、+10 金币），存不存都算。

### 背景音乐

- 曲子：Soothing Meditation (Without Voice)，作者 DanaMusic，Pixabay，9 分 44 秒。Pixabay 内容许可证允许免费用在应用里，不用署名；不能把音频单独拿出来卖或分发。页面上标了「Content ID Registered」，只影响把它放进 YouTube 视频这类平台，网页里播放没关系。
- 文件放在 `demo/public/audio/meditation.mp3`。原曲 9 分 44 秒、256 kbps、18.7 MB，响度 −13.9 LUFS，对冥想来说偏响。处理成：前 6 分钟，两遍响度标准化到 −23.5 LUFS（峰值约 −10 dB），开头 3 秒淡入、结尾 6 秒淡出，80 kbps 立体声，3.6 MB，循环播放。手机音量开到最大也不会吵。
- 点「开始」的那一下就开始放（手机浏览器要求声音必须由点击开始），2.6 秒淡入。关掉练习时 1.4 秒淡出。
- 进度条右边一个小音符，点一下关、再点开；关过就记住，下次默认不放。从对话里让小光开始冥想时，浏览器可能不让自动出声，这时音符显示成关着，点一下就有声音。
- iPhone 上网页改不了音量，所以淡入淡出用 Web Audio 的音量节点做。
- 服务器的静态文件加了按段读取（HTTP Range，返回 206）：iPhone 的 Safari 放音频必须要这个，否则放不出来。
