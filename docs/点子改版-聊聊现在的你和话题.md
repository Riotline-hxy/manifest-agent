# 点子改版：聊聊现在的你、话题

2026-11-08。同事出了一版「聊聊现在的你」的可视化（大卡片 + 插图），产品负责人觉得插图直观、可以吸收，但要贴我们自己的风格、照顾手机。
离线原型在 [docs/聊聊现在的你/方案.html](聊聊现在的你/方案.html)（两种页面 + 三个话题），选了方案 B「聊着来」，这一版把它做进 App。

## 一、聊聊现在的你：说说现在的你，我们从这里开始

**定位**：不是调设置，也不是深入探索自己。简单告诉小光现在的状态，然后小光带你从一个今天就能做的小步开始，往好里走。
做完的感觉应该是：「我已经说了我现在怎么样，接下来想看到一点进步，这个 App 开始带我一起变好了。」

**样子**（`public/js/tune.js`、`css/tune.css`）：一个像对话的全屏层。小光问一句，插图卡片放在小光的话下面，点一张就变成你说的话，小光回一句接着问。
不用多邻国那种按钮式选项（像在做题）：卡片是柔和的扁平小插图，颜色跟着主题；森林主题换成奶白线条、金色和嫩绿（紫色在深绿上发闷）。手机上两列。

**四个问题**（`core/relearn.py` 的 `STEPS`）

| 问 | 选项（插图） | 用在哪 |
|---|---|---|
| 最近的你，更像哪一种？ | 忙忙碌碌（缠在一起的线）/ 按自己的节奏（平缓的波）/ 正在变化（往上拐的线）/ 想慢下来（越来越稀的虚线和月亮） | 存成一条近况记忆，再做一次就更新那一条；也决定第一小步要不要挑不占时间的、放松的 |
| 接下来，最想在哪儿看到一点进步？ | 有愿望时第一个是「接着你的愿望」，再加作息和身体 / 学习和工作 / 心情和状态；没有愿望时第四个是和人相处 | 方向不是已有愿望时，小光起一个新愿望名，你勾了才建 |
| 现在，你能拿出多少劲？ | 一点点就好（两分钟就够）/ 每天一小会（十分钟左右）/ 可以多一点（半小时左右）。插图是同一个小花盆，苗一点点长高，最后开一朵小花 | 第一小步的大小 |
| 这一路，我怎么陪你比较好？ | 先听我说 / 陪我理一理 / 推我一把 / 给我打打气 | 写进陪伴偏好（和设置里同一项）；「推我一把」顺带把中断时改成轻轻提醒 |

每选一个，小光马上回一句（「最近事情不少呀。」「那就从很小的一步开始。」）。每题都能跳过。

**结束页**：答完那一下调一次模型（不思考，约 2.4 秒），拿到：
- 小光看到的你，一句话（例：「你累了想慢下来，把睡好动起来当作给自己松口气的起点。」）；
- 两个今天就能开始的第一小步，挑一个（例：「今晚睡前十分钟拉伸」「下午抽半小时走一走」）；
- 新愿望名（方向不是已有愿望时）。
下面列出会存的东西，都能取消勾选；底下的输入框可以写「还有什么想让我先知道的」。
「存好，开始吧」→ 回到对话，小光那句话和「「…」放进今天的计划了」已经在里面；「现在就做第一步」→ 直接打开两分钟启动，任务已经填好。
中途关掉什么都不留。练习经验照旧在答完时给。

模型的结果按这一次缓存在 `profile.relearn_end`，保存时不再调。模型不在时，按方向和劲头给一条通用的路（`FALLBACK`），小光说「好，我们就从这里开始。」

提示词在 `core/relearn.py` 的 `PROMPT`。真模型试过所有选法（原型里 60 种）；「可以多一点」以前会给太小的步子，加了一句「两个都按这个大小来」以后变成「挑一段跟读半小时」「晚饭后专注做事半小时」这种。

拿掉的问题：空闲时想做什么、最近希望多一点什么（这是在了解你这个人，挪去「话题」）；性格、提醒频率、有精神的时候（留在设置里）。

## 二、话题（点子里新的一组）

参考 Muse 的点子：每个话题是一个配好提示词的小场景，不知道聊什么时点一个就能开始。帮人看见自己，但要有聊下去的劲。

| 话题 | 点了替你发出的话 | 小光怎么陪你聊 | 聊完能存什么 |
|---|---|---|---|
| 完全空白的一天 | 想聊聊：如果明天什么安排都没有，我会怎么过。 | 一次问一个画面（几点醒、在哪、和谁、吃什么），像朋友好奇地问 | 说出注意到的一个点，你说要才记住 |
| 我的使用说明书 | 想聊聊：如果我有一份使用说明书，上面会写什么。 | 一项一项写：快没电的信号 → 最快的充电方式 → 请勿打扰 → 隐藏功能 → 正确的夸法；每条用说明书口吻写下来（「第 2 条：电量耗尽时，一个人去吃顿火锅就能满血复活」） | 整理成一份短短的说明书，你说要才一条条记住 |
| 平行宇宙里的你 | 想聊聊：平行宇宙里的另一个我。 | 挑一个岔路口，再一个画面一个画面地看那个你过得怎样，像一起拍小电影 | 那个宇宙里有什么想「偷」一点过来，一起想个今天能做的小做法，你想试才加成小步 |

**怎么接进对话**（`core/topics.py`、`core/agent.py`）：点了话题 → 回到对话，替你发出那句话（带着话题 id）→ 这一段对话里，话题提示词接在小光的系统提示后面。
话题进行中不打开别的练习（不给 `start_scene`、不走路由；试跑时发现会误开冥想）。30 分钟没再聊、或者开始两小时以后就算聊完。
**小光不推话题**：它们不在 `acts.FEATURES` 里（聊天里的推荐、主动消息都从那里挑），说明里也写了「TA 自己点，你不推荐」。
