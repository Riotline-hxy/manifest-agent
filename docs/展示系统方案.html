小光的统一展示系统 · 三个方案

四列都用同一段对话：TA 说焦虑 → 小光推荐冥想；TA 改一个小步；TA 说了一件小确幸；TA 讲了一个和愿望有关的瞬间。第一列是现在的样子，后三列是三个方案。不论选哪个，下面四条规矩都一样。

只有三种东西会出现在聊天里推荐（去试一个功能）、回执（我做了一件事）、待你确认（我提议，你点头才算）。
所有功能入口一个尺寸冥想、两分钟启动、感恩、学堂文章……同一个格子：图标 + 名字 + 一句介绍 + 一个按钮。
改动统一写法动词 + 是哪一项，有改前改后就写「旧 → 新」。小步、里程碑、习惯、好消息都一样。
只读的事不出卡片「看了看计划」「翻了翻记忆」「查了说明书」不再单独占一张卡，最多在气泡下面一行灰字。

三个方案对比

A 一张卡走天下B 签条 + 功能行C 横滑小卡 + 改动合并
推荐功能卡片，介绍和按钮都在和点子页同款的一行，最熟悉2–3 个小方卡让 TA 挑
改了东西一张卡一行签条多处合成一张，可展开
占的地方大最小中
多处改动时一处一张卡，会堆一处一行，三行以内还清爽最清楚
和「简约」的契合一般最好较好
工作量小（改现有卡片）中大（要做合并和横滑）

不管选哪个，背后都要做的

  • 加一个「推荐功能」的工具：小光想推荐时调用它，界面才知道要出入口；入口内容（名字、介绍、时长、颜色）从同一份功能清单生成，所以每个功能一样大。
  • 小光说「要不要试试冥想」以后不再自动跳转，由 TA 点「开始」；TA 自己说「我想冥想」时，仍然直接打开。
  • 改动的工具统一返回「改了哪一项、改前、改后」，界面统一画成 旧 → 新。
  • 撤销：小步、里程碑、习惯、好消息的改动，短时间内可以一键撤回（选 B 或 C 时建议做）。
  • 「看了看」「翻了翻」这类只读的动作不再出卡片。
