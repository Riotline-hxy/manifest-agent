# 点子改版：「许个愿」和「让愿望落地」（v3.15.0，v3.15.1 补了「自己写的话要听懂」）

原来的「聊聊你的愿望」和「聊聊现在的你」都在聊愿望、都以一个小步收尾，用户分不清，做一个就够了。
这次当作从零设计的两个功能，各管一件事：

| | 许个愿 | 让愿望落地 |
|---|---|---|
| 一句话 | 说出想要的，看见它实现的那一天；或者看看走过的路，给它添点信心 | 看看这周做得怎么样，把卡住的那一件调到做得成 |
| 管什么 | 「信」：确定一个新方向，或者坚定一个旧方向 | 「做」：让已有的愿望更做得成 |
| 背后的方法 | 显化里的愿景和见证；「最好的自己」想象；未来的自己给现在的自己留一句话 | 回看；微习惯（改小一点）；执行意图（挂在每天都会经过的时刻）；自我关怀（停一停不算放弃） |
| 收获 | 一张愿望卡（愿望、那一天的样子、未来的你说的话），放在蜕变计划里 | 「这周的打算」：改了哪一件、怎么改的，直接改进蜕变计划 |
| 不做 | 不加小步、不改计划 | 不建愿望、不讨论愿望本身 |
| AI | 只在最后调一次，写小光的一句话（新愿望还要愿望名和那一天的画面） | TA 要建议时（改小一点 / 再加一件 / 第一件事），或者 TA 自己写了一句时（听懂再回）；结尾的话是写好的 |

scene id 没变（`seven_steps_lite` 是许个愿，`relearn` 是让愿望落地），以前做过的次数、每日任务的「今日推荐」、主动推荐都接得上。
离线原型和设计过程在 `docs/聊聊现在的你/`（`新方案.html` 是第二版的说明，`许个愿.html`、`让愿望落地.html` 可以点着走）。

## 一、样子

对话样子的全屏层（`demo/public/js/tune.js`）：顶栏是标题、一句副标题和进度点；小光问一句，下面是插图卡片或文字卡片，点一张变成 TA 说的话，小光回一句接着问。

- 每一题最后一张都是「我自己写」（虚线边），点了底下出输入框。
- 每一题都能「先跳过」（开场选愿望、AI 建议那几题除外，那几题有「不用了」「先不加了」）。
- **能反悔**：底下左边一直有「上一步」，回到上一题；前面答过的题，点另一张卡片就从那一题重新走，后面的都撤掉。结尾也能上一步，存好以后就不能了。
- 小光的建议同一件事只问一次：上一步再回来不用重新等。
- 卡片里的字顶对齐（一行两张时，标题在同一高度），提示文字都控制在一行左右。

## 二、许个愿

开场：「今天想许一个新愿，还是给已有的愿望再添点信心？」卡片是已有的愿望（最多 3 个，现在的那个排第一）加「一个新的愿望」。没有愿望时直接走新愿。

**新的愿望**（4 题）
1. 想让生活的哪一块变好？身体与作息 / 学习与成长 / 关系与表达 / 心情与内在 / 生活与自由。
2. 具体一点，你想要的是……（写一句；按刚才的方向给三个例子，点一个也行）
3. 如果它真的实现了，那一天会有什么不一样？（按方向给三个画面）
4. 到那时，你最想对现在的自己说什么？

结尾：小光一句真心话（不复述卡片），一张愿望卡：愿望名、那一天（模型把 TA 选的画面写成一句现在时的「我……」）、未来的你说。
勾「把这张愿望卡放进蜕变计划」才存：新愿望（那一天写进 `vision_text`，分类先按愿望的字猜，猜不出按方向），未来的你说的话是轨迹上第一个瞬间「未来的我说：「…」」。
按钮：「存好」回到对话；「给它定第一件事」存好后接着打开让愿望落地，直接到「先定第一件事」。

**已有的愿望**（3～4 题）
1. 看看走过的路（不提问）：「「敢开口说英语」已经走了 23 天。」做完几个小步、打卡几次、留下几个瞬间，再摘一句 TA 自己写过的话。还没什么记录的愿望不报一串 0。
2. 这一路，最让你有感觉的是哪一刻？卡片是 TA 最近做完的小步和留下的瞬间（最多 3 个）。没有记录就跳过这题。
3. 现在想起这个愿望，你心里……还是很想要 / 更想要了 / 有点远了 / 说不清。选「有点远了」，小光把 TA 当初写下的样子拿出来，说它还在那儿。
4. 给接着往前走的自己，留一句话吧。

结尾：小光一句话，一张卡（走过的、最有感觉的一刻、留给自己的话）。勾了存成这个愿望轨迹上的一个瞬间，带上现在的心情。按钮「让它落地」。

## 三、让愿望落地

没有愿望：「还没有愿望呢。先许一个，再来让它落地？」按钮去许个愿。有几个愿望：先问「想调哪个愿望？」。

第一题下面先放这周的样子：这个愿望的习惯（本周打卡进度条）、放得最久还没做的小步（「放了 6 天」）、下一个里程碑还有几天。

```
这周的「X」，你觉得怎么样？
  有点卡 / 太满了 / 我自己写 → 是哪一件（先放下哪一件）→ 想怎么调它？
        改小一点   → 小光给两个更小的版本；习惯还能「频率降一档」；或者「不用改了」、自己定
        换个时间   → 习惯：起床后 / 午饭后 / 下课或下班后 / 睡前；小步：今天 / 明天 / 这个周末；或者自己写
        这周先停一停
        我想这样调……（自己写）→ 小光先听懂卡在哪，接一句，给两个对症的调整（改小 / 换个时间 / 这周先停）；或者「先不改了」、再自己写一句做法
  顾不上 → 只留一件最想保住的 → 改小一点，其余的习惯这周先停一停
  挺顺的 → 再加一点（小光给两个新小步）/ 保持现在就好
计划还是空的愿望：直接「先定第一件事？」（小光给两个，或者自己写）
```

**TA 自己写的话不照搬进计划（v3.15.1）。** 上线后发现：在「想怎么调」里写「我不知道怎么启动」，计划卡片上就照抄成「「X」：我不知道怎么启动」。这不是一个调整，是一个卡点，小光应该接住、帮 TA 调。现在：
- 「这周觉得怎么样」自己写：调一次模型（`FEEL`），听出最接近哪种（挺顺 / 卡住 / 太满 / 顾不上），接一句（不提问，下一题接着问），按那种往下走。
- 「想怎么调」自己写：多一题，调一次模型（`ADJUST`）。小光先说出听到的卡点，再给两个对症的调整，每个带类型：改小一点（不知道从哪开始就给做成它的第一下）/ 换个时间 / 这周先停一停。TA 挑一个，或者「先不改了」，或者自己写一句做法。结尾按 TA 挑的那种改计划。
- 真模型例子：小步「约 Mia 周末练口语」+「我不知道怎么启动」→「不知道怎么开口，那我们先只迈出第一小步，我陪你。」给「给 Mia 发一句，问周末有空吗」/「今天午饭后」；习惯「跟读一段对话」+「老是忘」→ 给「洗完澡后」这样的时候。

结尾：小光一句写好的话 + 「这周的打算」卡片，比如「「每天背 20 个单词」先改成「先背 5 个单词」」。
- 勾「改到蜕变计划里」才改。改法：习惯改名 / 降频率（`journey.edit_habit`）、挂到某个时候（新的 `habit.cue` 列，蜕变计划里习惯下面显示「每天 · 睡前 · 本周 1/7」）、这周先停（今天到周日记成「先不做」，不影响进度）；小步改日子、更小的第一下加成今天的新小步。
- 习惯换到起床后 / 午饭后 / 下课后 / 睡前，多一行「每天 HH:MM 提醒我」，默认不勾，勾了建一个每天的例行提醒。
- 选的是小步（或者新加了一件），多一个「现在就做」：存好后打开两分钟启动，任务已经填好。
- 「保持现在就好」「不用改了」：不出卡片，小光说一句就结束。

## 四、代码

| 文件 | 管什么 |
|---|---|
| `demo/public/js/flows.js` | 两个流程的问题、选项和分支（前端），答案怎么交给后端 |
| `demo/public/js/tune.js` | 通用的对话层：一题一题、上一步、改前面的答案、结尾的卡片和保存 |
| `demo/public/js/ills.js` | 插图（颜色跟主题，森林主题有自己的一套，在 `css/tune.css`） |
| `demo/core/flows.py` | `POST /api/flow`：start（TA 自己的记录）/ suggest / finish（算结尾，存进 `profile.flow_end`）/ save（只存勾了的） |
| `demo/core/wish_flow.py` | 许个愿：记录、提示词 `NEW` `KEEP`、结尾、存法 |
| `demo/core/relearn.py` | 让愿望落地：这周的样子、提示词 `SMALLER` `ADD` `FIRST` `FEEL` `ADJUST`、结尾（不调模型）、存法 |
| `tools/flow_eval.py` | 用真模型把几种结尾和建议跑一遍，改提示词以后看效果 |

- 答题时什么都不写，也不进对话；答完那一下给练习经验（存不存都算），在结尾改了答案再答完不重复给，同样的答案也不重复调模型。
- 中途关掉（`/api/scene/cancel`）或者结尾不存（`/api/scene/discard`）：这次的答案清掉。同一次不能存两遍。
- 存好后小光的那句话进对话。
- 老的 `/api/scene/start` 对这两个 id 返回 404（它们只走 `/api/flow`）。
- 以前「聊聊现在的你」的近况记忆、陪伴偏好还在；陪伴偏好在设置里改。
