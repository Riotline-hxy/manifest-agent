# 点子改版：「显化你的愿望」和「调整现有计划」

2026-11-08。上一版的「许个愿」「让愿望落地」分支太多、元素耦合在一起，用户说不清每个功能是干什么的。
这一版照「两分钟启动」的思路重做：一条说得清的流程，模型在该出力的地方出力，用户看到结果、不对能改，最后勾了的才存。
演示和设计过程在 `docs/显化与调整/`（`方案.html` 可以点着走；`gen.py` 用同一套提示词让真模型预先跑出演示数据）。

scene id 没变（`seven_steps_lite` 是显化你的愿望，`relearn` 是调整现有计划），以前做过的次数、每日任务的「今日推荐」、主动推荐都接得上。

## 一、显化你的愿望

**流程**：先选已有的愿望（从第 2 步开始，6 步，坚定信念）还是一个新的愿望（完整 7 步）→ 每一步一屏：小光问一句，用户点卡片或者自己写 →
把回答、前面的回答、这个愿望和这一步的提示词发给模型 → 模型接住用户的话，给出这一步的收获，用户挑一个、自己写、或者上一步 →
七步走完，小光写一张小纸条，配一张显化卡，勾了的才存。

| 显化七步 | 小光问 | 模型给 |
|---|---|---|
| 1 清晰愿景（新愿望才有） | 你想要什么？→ 挑一个更具体的 → 闭眼想象它实现了，那一刻的感觉 | 两个更具体的版本；那一刻的画面（「我……」） |
| 2 消除怀疑 | 心里有没有一个声音说「我做不到」？ | 接住那个声音；两句对着它的肯定语 |
| 3 调整行为 | 如果你已经是实现了它的人，今天会做什么？ | 两件今天能做、稍微走出舒适区的小事；挑了再接一句 |
| 4 克服考验 | 最近有没有想将就、想退回去的时候？ | 接住（不评判、不失望）；两句「下次它出现时，我会……」 |
| 5 无条件感恩 | 什么让你觉得有幸？（或者写一句「我必须……」） | 改写成「我有幸能……」 |
| 6 嫉妒变动力 | 看到活成你想要样子的人，你心里…… | 这份感觉说明你真正想要什么；可以向 TA 学的一件事 |
| 7 信任 | 想到它什么时候会来，你心里……（很急 / 怕它一直不来 / 能慢慢等）→ 挑一句心急时对自己说的话 | 接住这份心情，把「今天能做的」和「交给时间的」分开；两句交给时间的话 |
| 走完 | （不提问） | 一张小纸条：用上你说的那个声音、挑的那句话、今天要做的事，串成你自己的一段路；最后一句落在好好爱自己，写在显化卡最下面 |

第 7 步和结尾是按产品负责人的意见重做的：原来是「我愿意相信 / 还有点不安」二选一，接一句不痛不痒的话就发卡片。现在第 7 步先接住 TA 着急或者害怕的心情，帮 TA 分开能做的和交给时间的；走完的小纸条一定用上 TA 这一路说的具体内容。

**显化卡**：结尾只放一条横栏（星星图标 + 「我的显化卡」+ 愿望名 + 「查看」），点开是整张卡：顶上是主题色渐变和几颗星，写着日期、愿望名、走了几步；
下面一步一行（步数圆点 + 哪一步 + TA 的那句，像一条小路连起来），最下面是小光那句自爱的话。× 或者 Esc 收起。

**显化卡会存的**（都能取消）：新愿望和那一刻的样子 → 蜕变计划（那一刻写进 `vision_text`，愿望名去掉「我想」）；肯定语 → 愿望轨迹上的一个瞬间「对自己说：「…」」；
今天去做的事 → 今天的小步（「现在就去做」打开两分钟启动）；感恩 → 幸福墙；那个怀疑和考验 → 记忆（默认不勾）；每天 08:00 提醒念一遍肯定语（默认不勾）。

**模型**：每一步答完调一次（不思考，约 2 秒），走完再写一次小纸条；新愿望大约 10 次。同样的答案只问一次（上一步再回来不用等）。模型没连上时每一步都有写好的话，照样能走完。
提示词在 `demo/core/manifest_flow.py` 的 `P`。

## 二、调整现有计划

**流程**（和两分钟启动一样清楚）：用户答三个关于现在状态的小问题（点卡片或者自己写）→ 把回答、TA 现在的整份计划（每个愿望下的习惯和本周打卡、没做的小步、里程碑）和提示词发给模型 →
模型给一份调整方案：一句看到的你 + 0～5 条具体改动（改哪一项、怎么改、为什么）→ 用户觉得哪条不对就取消，或者说一句，把意见、上下文和上一版方案发给模型重新调 →
点「一键调整」，勾了的改进蜕变计划，看到改了什么；勾了「让小光记住现在的你」才记成一条近况（再做一次就更新那一条）。

| 问题 | 选项 | 影响什么 |
|---|---|---|
| 最近的你，更像哪一种？ | 忙忙碌碌 / 按自己的节奏 / 正在变化 / 想慢下来 | 改动的力度；要不要停一停 |
| 现在，你能拿出多少劲？ | 一点点就好 / 每天一小会 / 可以多一点 | 留下来的事改到多小 |
| 这阵子的计划，做起来怎么样？ | 挺顺的 / 有点卡 / 太满了 / 顾不上（上面先放现在的整份计划） | 改小、减掉，还是加一点 |

**模型能做的改动**是固定几种，每种都对得上 App 里真的能改的东西：习惯改小一点（改名）/ 降频率 / 挂到每天某个时候（`habit.cue`，蜕变计划里习惯下面显示）/ 这周先停（今天到周日记成先不做）；
小步先做第一下（加一个今天的新小步，原来的还在）/ 换个日子（明天、后天、周几、这个周末……）；里程碑推后几天；顺的时候加一小步。
后端会把模型写的名字对回计划里的那一项：对不上的、类型不对的（比如给小步用习惯的改法）、同一项第二条，都不给用户看。最多 5 条。
计划是空的：模型给现在的愿望加 2～3 个很小的开始。还没有愿望：先去「显化你的愿望」。

**模型**：出方案调一次，每重新调一次再调一次（约 3 秒）。提示词在 `demo/core/relearn.py` 的 `PLAN`、`REVISE`。

## 三、样子和代码

两个都是对话样子的全屏层（`demo/public/js/tune.js`）：顶栏标题 + 一句小字（显化里是「显化第 N 步 · 步骤名」）+ 进度点；每一题都能「我自己写」，
底下有「上一步」，前面答过的题点另一张就从那一题重新走，结尾也能上一步。答题时什么都不写，也不进对话；答完那一下给练习经验；中途关掉、结尾不存，这次的答案清掉。

| 文件 | 管什么 |
|---|---|
| `demo/public/js/flows.js` | 两个流程的问题、选项，什么时候调模型，答案怎么交给后端 |
| `demo/public/js/tune.js` | 通用的对话层：一题一题、上一步、改答案；结尾两种（显化卡 / 调整方案 + 重新调 + 一键调整） |
| `demo/public/js/ills.js` | 插图（颜色跟主题，森林主题有自己的一套，在 `css/tune.css`） |
| `demo/core/flows.py` | `POST /api/flow`：start（TA 自己的记录）/ step（调模型的一步；调整计划里是 revise）/ finish（算结尾，存进 `profile.flow_end`）/ save（只存勾了的） |
| `demo/core/manifest_flow.py` | 显化你的愿望：每一步的提示词、小纸条、显化卡、存法 |
| `demo/core/relearn.py` | 调整现有计划：整份计划、方案和重新调整的提示词、改动对回计划、一键调整 |
| `tools/flow_eval.py` | 用真模型把两条流程跑一遍，改提示词以后看效果 |

## 四、真模型试跑（DeepSeek flash，不思考，温柔）

`python tools/flow_eval.py`：

- 新愿望「换一份喜欢的工作」→ 心里的声音「已经太晚了」→ 肯定语「我现在开始也不迟」→ 今天去做「查三家附近设计公司，记下名字」→ 很急 →
  小纸条：「阿青，心里那个说「已经太晚了」的声音，你打算对它说「我现在开始也不迟」。今天先查三家附近的设计公司，把名字记下来。不着急，你已经在走的那条路上了。」
  最后一句：「先对自己温柔一点，你的节奏就很好。」
- 已有的愿望「敢开口说英语」+「怕别人怎么看」+ 怕它一直不来 → 「这种怕挺正常的。今天先试着用英语点杯咖啡，至于它什么时候来，先放一放。」
- 调整计划「忙忙碌碌 · 一点点就好 · 太满了」→ 背单词改成每天 2 个、跟读这周先停、约 Mia 挪到这个周末、里程碑推后 7 天、放下手机挂到每晚洗漱完；
  再说「背单词我不想减，别的可以」→ 只拿掉背单词那条，别的不变。「正在变化 · 可以多一点 · 挺顺的」→ 「照着计划走就好」，不改。
