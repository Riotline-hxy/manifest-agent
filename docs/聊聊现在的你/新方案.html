按上一版的意见重新排了问题和流程，v3.15.0 已经上线（说明在 docs/点子改版-许个愿和让愿望落地.md）。这两个原型里小光的话和 AI 给的建议，是用现在的小光（DeepSeek flash，温柔）预先跑好的。

主题：

这一版改了什么

  • 回到 B 的样子：顶栏是标题、一句副标题和进度点，不再放显化七步那一行（顺序对不上，放着反而奇怪）。
  • 问题连成一条线：每一题都接着上一题的答案问，读下来像一段对话，不再是一个个独立的练习。去掉了「闭眼三秒」「念出来」「交出担心」这些仪式步骤。
  • 结尾不再拼句子：卡片上放 TA 自己选的和写的；小光那句话不复述卡片上的内容，只说自己真心的一句。
  • 落地不带方向：不再给 TA 安排「如果……就……」，改成 TA 自己说这周怎么样、哪一件、想怎么调，小光只在 TA 要「改小一点」「加一件」时给两个建议。
  • 每一题都能自己写：最后一张卡片都是「我自己写」；AI 给的建议旁边都有「不用了」，也都能跳过。
  • 能反悔：底下左边一直有「上一步」；前面答过的题，点另一张卡片就从那一题重新走，后面的都撤掉。结尾也能上一步。
  • 卡片对齐：一行两张时标题在同一高度；「换个时间」的提示缩成「定个固定的时候」。

一、分工

许个愿管 「信」，让愿望落地管 「做」。

许个愿让愿望落地
一句话说出想要的，看见它实现的那一天；或者看看已经走过的路，给它添点信心看看这周做得怎么样，把卡住的那一件调到做得成
背后的方法显化里的愿景和见证；「最好的自己」想象；未来的自己给现在的自己留一句话回看；微习惯（改小一点）；执行意图（挂在每天都会经过的时刻，加提醒）；自我关怀（停一停不算放弃）
收获一张愿望卡（愿望、那一天的样子、未来的你说的话），放在蜕变计划里「这周的打算」：改了哪一件、怎么改的，直接改进蜕变计划
不做不加小步、不改计划不建愿望、不讨论愿望本身
多久一次立新愿、或者想放弃的时候一周一次，或者卡住的时候
AI只在最后调一次只在 TA 要建议时调一次（改小一点 / 加一件）；结尾的话是写好的

三、让愿望落地

第一题下面先放这周的样子（习惯打卡的进度、放着没动的小步、下一个里程碑），TA 自己说感觉怎么样，后面跟着 TA 的回答走。

手机 390 · 可以点

单独打开 →

这周感觉怎么样？（2～4 题，看 TA 怎么答）

有点卡 → 是哪一件？ → 想怎么调它？
　　改小一点 → AI 给两个更小的版本（或者「不用改了」、自己定）
　　换个时间 → 起床后 / 午饭后 / 下课或下班后 / 睡前 / 自己写；结尾多一行「每天 22:00 提醒我」，默认不勾
　　这周先停一停 · 我想这样调……（自己写）
太满了 → 先放下哪一件？ → 想怎么调它？（同上）
顾不上 → 只留一件最想保住的 → 把它改小一点，其余这周先停一停
挺顺的 → 再加一点（AI 给两个这周能做的新小步）/ 保持现在就好
我自己写 → 跟着「有点卡」那条走
选的是小步（不是习惯）时，结尾多一个「现在就做」，直接打开两分钟启动。

结尾：这周的打算

  • 一张卡片列出这周改了什么（「「每周跟读 3 次」先改成「每周跟读1次，只读2分钟」」），勾选「改到蜕变计划里」才改。
  • 小光那句话按 TA 走的那条路写好了，不调模型（「小一点，这周就做得成。」「停一停不算退，下周再接上。」）。
  • 选了「保持现在就好」或者「不用改了」，就不出卡片，小光说一句就结束。

五、对照四个标准

  

    
直观简洁3～4 题；每题一张图一句话；没有术语、没有七步标签；进度点一眼看出还剩几题。

    
轻松易用点一张卡就往下走；每题都能跳过、都能自己写；AI 的建议旁边有「不用了」；勾了的才存。

    
懂用户用 TA 自己的记录：走了几天、做完的小步、留下的瞬间、这周的打卡进度；后面的问题跟着前面的答案变；有点远了、顾不上，小光先接住，不催。

    
收获清晰可见许个愿留下一张愿望卡（愿望、那一天、未来的你说的话），放在蜕变计划里；落地留下「这周的打算」，计划直接改好，需要的话有提醒。
