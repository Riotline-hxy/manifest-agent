# manifest · 网页版试设计（Muse 式个人伙伴）

2026-10-21。基于《显化｜产品创意与核心功能构想》和 9 条批注重新设计，交互骨架参考 Meta 的 Muse，没有沿用旧 MVP 的界面。

## 打开方式

- 直接双击 `index.html` 即可（不需要安装任何东西）。
- 或在本文件夹执行 `python -m http.server 8790`，然后访问 `http://localhost:8790`。
- 访问 `index.html#demo` 会直接载入 12 天示例数据；`#demo/records`、`#demo/ideas` 等可以直接打开对应页面，方便演示。

原型说明：伙伴的回复由本地脚本生成，没有接入大模型；数据只保存在浏览器的 localStorage 里。

## 从 Muse 借了什么

| Muse 的做法 | 在 manifest 里 |
|---|---|
| 只有一条一直延续的主对话，像给一个人发消息 | 「对话」就是主线，不分会话；按日期分隔 |
| 大项目可以开 side chat | 「旁聊」：每个愿景可以单独开一个，伙伴记得主线内容 |
| 用户自己创建、命名的头像 | 首次进入先给伙伴起名、选颜色；圆形小伙伴是全站唯一的饱和色 |
| 头像下方显示它正在做什么，点开看活动记录 | 顶部状态行（如「有 2 条猜测等你确认」）；点头像打开抽屉：打算做的、做过的、约定 |
| 主动消息必须值得打扰，频率可调 | 早上的「今日发现」、晚上 8 点聊收获；在「灵感」里选 多一点 / 刚好 / 少一点 / 先别打扰 |
| 前几天用 tips 帮新用户上手 | 输入框上方的「可以试试」提示，可关闭 |
| Ideas 标签按目标和习惯给建议 | 「灵感」：每条都标出来源（来自哪个愿景、因为你说自己拖延……） |
| Goals 标签显示在追踪的事和计划 | 「愿景」：为什么想要、小步骤、试过几次；可改、可先放一放 |
| 记忆文件可读可改 | 「我」：每条记忆标明 你说的 / 伙伴猜的 / 你确认过，可确认、修改、忘掉 |
| 难以撤销的操作用结构化卡片确认 | 伙伴的猜测必须经「对，记下 / 不太对」卡片确认才算数 |
| 用交互式成果代替大段文字 | 聊天里的画像卡、一小步卡、偷懒日卡、蜕变报告卡 |

## 构想 PDF 的功能落在哪

| 构想 | 位置 |
|---|---|
| 功能 1：自我探索与个人画像 | 首次对话：三个夸自己的词、三个不满意的词、MBTI/星座（可跳过）→ 初步画像卡 + 2 条待确认猜测 → 「一年后的你」 |
| 批注：三档探索时长 | 引导页可选 1–5 / 5–15 / 15–30 分钟，决定问题数量；「我」里可以随时补几道题 |
| 功能 2：愿景与行动探索 | 说出「我希望……」时，伙伴提议放进愿景并开旁聊，依次追问为什么、已有什么，再给一个小尝试 |
| 功能 3：每日自我发现 | 每天一个问题（灵感页 + 右侧栏 + 主动消息）；回答后存进「新发现」，并提出一条待确认的猜测 |
| 功能 4：好消息与偷懒日 | 输入框左边的星星切换到「记一条好消息」，右边的月亮是「今天想偷懒」；记录页没有连续打卡，也不会清零 |
| 功能 5：10/30 天蜕变报告 | 记录页或聊天卡片打开；写成一段话而非统计表；分享前可逐项选择显示内容，可复制文字版 |
| 长期成长记忆 | 「我」页的记忆列表；猜测与事实分开存放 |

## 视觉

- 白底黑字，大量留白；层级靠字号和字重，而不是一张张卡片。
- 唯一的饱和色是伙伴的颜色（晨雾蓝 / 薄荷 / 杏子 / 丁香），用于头像、提示和今日发现。
- 借鉴《好消息》的一点手绘感：只出现在好消息的五色小星星上。
- 自适应：宽屏三栏（导航 / 对话 / 今天），中等宽度两栏，手机为底部五个标签。
- 支持键盘焦点和「减少动态效果」设置。
